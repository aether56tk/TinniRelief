# Contributing to TinniRelief

Keep contributions focused on tinnitus self-management/support, accessibility, privacy, and reproducible research tooling.

- Do not commit identifiable health information.
- Avoid claims of cure, treatment efficacy, or clinical validity without appropriate evidence.
- Preserve comfortable-listening and safety boundaries.
- Add or update tests when changing application behavior.
- Document data-model changes and export compatibility.

Run:

```bash
npm test
```
