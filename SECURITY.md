# Security Policy

TinniRelief stores self-management information locally in the browser. Do not upload personal health information, identifiable diary entries, or private recordings to the public repository or GitHub issues.

Do not publicly post credentials, sensitive personal data, or exploitable details. Contact the maintainer privately through the GitHub profile.

Relevant reports include unsafe import/export handling, XSS, unsafe browser storage behavior, dependency/workflow vulnerabilities, and unintended disclosure of locally stored data.

TinniRelief is not a diagnostic system and should not be used to bypass professional assessment or medical-device safeguards.
